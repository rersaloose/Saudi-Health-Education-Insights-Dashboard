Overview

This dashboard provides a comprehensive view of student enrollment statistics at King Saud bin Abdulaziz University for Health Sciences (KSAU-HS) across all campuses, colleges, and academic years from 2016/2017 to 2023/2024. It enables administrators and stakeholders to explore trends, compare campuses, drill into college-level data, and gain actionable insights through interactive visualizations.

Data Source

All data displayed is sourced from the publicly available KSAU-HS student enrollment dataset (GetStudentsDataPublic.json). The dataset covers three main categories:

  • Gender — Male and female enrollment per academic year
  • Academic Degree — Bachelor's and postgraduate enrollment per year
  • Branch & College — Enrollment broken down by campus (Riyadh, Jeddah, Al-Ahsa) and college

Loading & Error Handling

Each card independently handles three states:

  • Loading — A spinner with "Loading data..." appears while data is being fetched
  • Error — If data fails to load, an error message is shown instead of zeros
  • Empty — If no data exists for the selected filters, a "No data available" message is displayed rather than showing zeros
